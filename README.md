# stringbed

A library of tennis racquet assets for web and app projects.

Each racquet is a small data file. A generator turns it into a lightweight 3D model that
keeps what makes the frame recognisable: head shape, beam, throat, string pattern and
colourway.

> **Status: design only.** No code or assets yet. The design and the implementation plan are
> written and ready to build from.

## Planned for v1

- 15 racquets, three each from Yonex, Babolat, Wilson, Solinco and Prince
- Binary glTF (`.glb`) per racquet, with named parts so grips and strings can be swapped
- A GitHub Pages gallery to browse, inspect and download every asset

## Later

- **Customization**: grips, strings, dampeners and more
- **Other visual styles**: toon-shaded, pixel, voxel and others, not all of them 3D
